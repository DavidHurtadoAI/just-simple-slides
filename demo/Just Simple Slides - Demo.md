### One idea, one slide

###### Heading levels do not dictate the layout

The **first heading** is the title. The **second heading** is the subtitle. Everything else belongs to the body.

- Keep using the Markdown you already know.
- Separate slides with three dashes: `---`.

# A little more detail

## Tables, lists, code, and callouts are still Markdown

| Content | Automatic layout |
| --- | --- |
| Text | Uses the available slide width |
| Image | Large and centered |
| Text + image | Side by side |

> [!tip] Keep a slide focused
> The plugin scales dense content to fit. Shorter slides are easier to read.

```md
# A title
## An optional subtitle

Your text goes here.

![[your-image.png]]
```

# Ready to present

## Use your keyboard or click to advance

- **→ / Space / Page Down**: next slide.
- **← / Page Up**: previous slide.
- **Home / End**: first or last slide.
- **Esc**: return to editing.

The presentation uses your current Obsidian background, colors, and fonts.
